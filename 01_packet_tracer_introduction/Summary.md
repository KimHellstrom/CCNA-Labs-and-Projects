# Lab 01: Packet Tracer Introduction & Topology Setup

* **Source Material**: Jeremy's IT Lab (CCNA Day 1)
* **Objective**: Familiarize with Cisco Packet Tracer interface, device placement, and physical/logical cabling connections based on a multi-branch enterprise topology.

## Topology Overview

The network simulates two remote branch offices connected across the Internet, featuring firewalls, core routers, switches, end-user PCs, servers, and an attacker laptop node.

### Devices Used:
* **Routers**: Cisco 2911 (x2 branch routers, x1 Internet router)
* **Switches**: Cisco 2960-24TT (x2 layer 2 access switches)
* **Firewalls**: Cisco ASA 5505 (x2 edge firewalls)
* **Endpoints**: x2 PCs, x2 Servers, and a Laptop (Attacker node)

## Verification Notes & Observations
* Verified interface link lights across switches and routers. Red interface markers indicate unconfigured or shutdown states prior to IP addressing and routing setup.
* Used Packet Tracer's automatic connection selection tool to map baseline physical media types between disparate hardware interfaces.
