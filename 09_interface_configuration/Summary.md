# Lab 09: Interface configuration

* **Source Material**: Jeremy's IT Lab (CCNA Day 9)
* **Objective**: Manually reconfigure network interfaces duplex speed, descriptions and verify correct IPv4 addresses.

## Topology Overview

A LAN setup with 100Mbps full duplex speed.

### Interface information:
* **Interface description**: A place to write quick important notes, such as source and destination interfaces.
* **Full duplex**: Allows two-way communication between interfaces simultaneously.
* **Half duplex**:  Allows two-way communication between interfaces but one interface at a time.

## Verification Notes & Observations
* Verified interface configuration:
>show startup-configure: shows each interface description, IPv4 address, duplex settings and that interface/media is up and running correctly.

>ping ip-address: quick way to check connectivity and speed between two devices regardless of distance


  ### extra:
  >hostname name: renames the current device
